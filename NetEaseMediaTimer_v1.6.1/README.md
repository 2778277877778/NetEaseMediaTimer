# 网易云定时播放助手（NetEase Media Timer）

> 基于 Windows **GSMTC 系统媒体会话 API** 的网易云音乐定时播放小工具 · 纯图形界面 · 单文件 exe 开箱即用
>
> **版本 v1.6.1 ｜ 平台 Windows 10 (1903+) / Windows 11 ｜ 仅供技术学习演示**

---

## ⚠️ 免责声明（使用前必读）

1. 本程序仅用于 Windows GSMTC（Global System Media Transport Controls）系统媒体会话 API 的**技术学习与演示**；
2. **自动化挂机存在平台风控风险**，可能违反网易云音乐用户协议，请自行评估并承担使用后果；
3. 本程序**不启动**网易云、**不打开**歌单、**不负责**初始播放、**不模拟**鼠标键盘、**不读写**网易云进程数据；
4. 全部播放/暂停控制仅通过 Windows 系统级媒体接口完成，不干扰鼠标键盘的正常使用。

## 🚀 快速开始（exe 用户）

### 1. 手动完成网易云前置操作（必须！本程序绝不代劳）

1. **手动打开**网易云音乐 PC 客户端；
2. **手动选好歌单**，把播放模式切换为**列表循环**；
3. **手动点击播放**，让音乐处于播放状态；
4. 自检：按一下键盘媒体键或调出 Windows 媒体浮层，能看到网易云曲目卡片 = 系统媒体控件（SMTC）就绪；**若看不到网易云卡片，请务必阅读 FAQ 的 Q1**——网易云 Win32 原版客户端不注册 SMTC，需要一次性安装 InfLink-rs 插件（2 分钟）。

### 2. 启动程序

双击 NetEaseMediaTimer.exe（首次运行如遇 SmartScreen 提示，点"仍要运行"；杀软误报请添加信任）。

### 3. 选择模式

- **立即开始计时**：填入时长（分钟）→ 点击 ▶，适合调试；
- **每日定时**：填入时长与"时 : 分"→ 点击 ⟳，每天到点自动开始，窗口可最小化驻留；
- **停止全部**：随时点击 ■ 终止。

倒计时走完后，程序自动向网易云发送系统媒体"暂停"指令，任务结束。

## 🧩 工作原理

1. 通过 winsdk / py-now-playing 访问 Windows GlobalSystemMediaTransportControlsSessionManager（GSMTC）；
2. 按 AUMID 关键词（netease / cloudmusic / 网易云）+ 应用显示名称双重匹配网易云媒体会话；
3. 读取 GlobalSystemMediaTransportControlsSessionPlaybackStatus 判断播放状态；
4. 状态 = Paused 时调用 try_play_async() 恢复；结束/停止时调用 try_pause_async() 暂停；
5. tkinter 主线程 + asyncio 后台线程架构，线程间经安全队列通信，界面零卡顿。

## 🔁 兼容模式（网易云无 SMTC 时自动生效，无需任何插件）

网易云 Win32 原版客户端（含 3.1.x）不向 Windows 注册 SMTC 媒体会话。程序在启动检测和倒计时轮询中若发现网易云进程在运行但没有 SMTC 会话，会**自动进入兼容模式**：

| 能力 | 实现方式 | 说明 |
| --- | --- | --- |
| 播放状态检测 | WASAPI 音频会话峰值电平 | 有声 = 播放中，静默 = 暂停/停止；纯系统音频接口观察，零打扰 |
| 当前曲目显示 | 读取网易云主窗口标题（歌名 - 歌手） | 状态灯与日志会显示正在播放的曲目，零交互读取 |
| 完整自检 | 【检测会话】一键输出全链路报告 | 进程 / SMTC 会话 / 音频会话 / 电平 / 静音 / 音量 / 曲目 / 结论 |
| 到点真暂停（默认） | 冻结网易云进程（NtSuspendProcess） | 音乐立即停止、歌曲不再推进；与系统睡眠同一机制，不模拟任何输入。冻结期间网易云界面无响应属正常现象，请勿操作；停止任务/退出程序/次日定时都会自动解冻并续播 |
| 到点仅静音（取消勾选时） | 网易云音频会话静音（SetMute） | 音乐继续走、无声；只作用于网易云自身 |
| 静音挂机（默认） | 倒计时开始即静音 | 音乐继续走时长、不出声；开声音选项开启后才解除静音 |
| 开声音（可选勾选） | 解除网易云会话静音 | 勾选「倒计时期间开声音」后定时到点自动放声 |
| 双向静音守卫 | 倒计时中自动纠正非本程序执行的静音/取消静音 | 开声音模式恢复声音；静音挂机模式恢复静音 |
| 意外暂停守卫 | 倒计时中检测到暂停并尝试自动恢复播放 | 有无障碍树可用时通过播放栏按钮恢复，否则提示 |
| 手动停止 | 自动解冻 + 解除本程序静音 | 停止任务＝交还控制权：网易云恢复播放并放出声音；你在音量合成器里自己静音的不受影响 |

**兼容模式的边界（请知悉）**：

1. 静音期间歌曲会继续往下播放（列表循环在走，只是不出声），不是严格意义的暂停；
2. 兼容模式无法远程恢复播放——若网易云被手动暂停，请保持它在播放（到点后程序会自动放声；若它处于暂停，日志会提示）；
3. 若希望获得真正的暂停/恢复与曲目识别，安装 BetterNCM + InfLink-rs 插件（见 FAQ Q1），程序检测到 SMTC 会话后会自动升级为完整控制模式。

## ⏱ 长时间挂机指南（示例：连续 5 天自动循环）

目标：**每天 21:30 自动播放设定时长 → 自动暂停音乐 → 次日同一时间再来**，全程无人值守。

1. 手动打开网易云 → 选歌单 → 列表循环 → 点播放（首次配置时做一次即可，之后保持客户端开着）；
2. 启动本程序 → 填入时长（如 90）与时间（如 21:30）→ 点击【启用每日定时任务】（默认静音挂机刷时长 + 到点真暂停；想外放就勾选「倒计时期间开声音」，不想要冻结就取消「到点后真暂停」）；
3. 勾选「挂机期间防止系统休眠」（默认已勾选）：程序在驻留与倒计时期间保持系统唤醒，显示器可以正常关闭，不影响挂机；
4. 笔记本请插电，并在电源选项中关闭自动睡眠；台式机无需处理；
5. 建议同时勾选「开机自动启动」，并在网易云客户端内开启其开机自启——若中途断电重启，两者都会自动恢复（网易云恢复后需手动点一次播放）；
6. Windows 更新可能夜间自动重启：请在 设置 → Windows 更新 → 高级选项 → 使用时段 中避开挂机时段；
7. 之后每天自动循环：定时到 → 自动开始播放 → 时长结束自动暂停 → 等待明天；
8. 每小时日志输出一次挂机心跳（含连续驻留天数与累计执行次数）；若系统发生过睡眠，唤醒后日志会记录并自动补跑当天定时。

## ❓ 常见问题（FAQ）

**Q1：网易云明明在播放，日志却一直提示"未找到网易云媒体会话"？**

先说结论（经实测与社区文档双重确认）：**网易云音乐 Win32 原版客户端（含 3.1.x）本身不向 Windows 注册 SMTC 系统媒体会话**。这是客户端官方限制——任何 GSMTC 工具（包括 Windows 自带的媒体浮层）都看不到它，不是本程序故障。

解决方法 ①（推荐，一次性 2 分钟）：给网易云安装 BetterNCM 扩展框架 + InfLink-rs 插件，让它注册标准媒体会话：

1. 关闭网易云音乐客户端；
2. 从 GitHub 下载 BetterNCM Installer（仓库：std-microblock/BetterNCM-Installer）并运行，它会自动完成注入；
3. 打开网易云音乐 → 点右上角的扩展图标 → 扩展市场 → 搜索并安装 **InfLink-rs**（注意：务必安装 Rust 重构版 **InfLink-rs**，不要安装旧版 InfLink，两者共存会冲突失效）；
4. 按提示重载客户端；验证：Win+A 通知中心或音量弹窗里能看到网易云的曲目卡片即成功；
5. 重新打开本程序 → 点【检测会话】→ 应能看到网易云会话与播放状态。

解决方法 ②：改用支持 SMTC 的播放器（QQ音乐、Spotify、Edge/Chrome 浏览器网页播放等）——本工具的控制原理对所有 SMTC 会话有效。

补充：若扩展市场报 403，进入 BetterNCM 设置更换扩展源；若注入后仍无会话，可能是客户端版本暂不兼容该插件，等待插件更新即可。

**不想装插件？** v1.3 起程序会自动进入兼容模式（音频电平检测 + 会话静音控制），到点停声/放声照常工作，只是没有真正的暂停与曲目识别——详见「🔁 兼容模式」章节。

**Q2：双击 exe 没反应 / 被杀毒软件删除？**

- 未签名的单文件 exe 常见误报，恢复文件并添加信任即可；
- 若仍无窗口，查看程序目录下是否生成 crash.log 并据此排查。

**Q3：倒计时期间我可以手动暂停网易云吗？**

- 不建议。程序会把"暂停"视为异常并自动恢复（这正是它的职责）；需要人工控制请先点【停止全部任务】。

**Q4：支持其他播放器吗？**

- 凡是注册了 Windows 系统媒体会话（SMTC）的播放器均可被控制，但匹配关键词面向网易云桌面版设计。

**Q5：每次开机需要重新设置吗？**

- 不需要。参数自动保存在程序目录的 config.json 中。

**Q6：电脑中途睡眠/休眠了怎么办？**

- 勾选了防休眠（默认）：系统不会入睡，挂机不中断；
- 未勾选：睡眠期间倒计时暂停，唤醒后程序自动继续；当天错过的定时点会在唤醒后立即补跑一次，日志中会明确记录。

**Q7：程序会被 Windows 长时间运行后杀掉吗？**

- 不会。Windows 不会主动结束普通桌面程序的进程；真正需要防范的是睡眠/休眠/关机/系统更新重启，v1.2 已通过防休眠开关、睡眠唤醒自动恢复、开机自启与每小时心跳来应对。
